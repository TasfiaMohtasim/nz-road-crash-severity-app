# NZ Road Crash Severity Dashboard

This is the lightweight Streamlit deployment for the New Zealand Road Crash Severity Prediction project.

The dashboard includes:
- crash overview
- contextual feature summaries
- model performance
- severe-class error analysis
- SHAP feature importance

## Run locally

Install packages:

pip install -r requirements.txt

Run the app:

streamlit run app.py

The dashboard uses:
data/combined_context/CAS_National_Context_enriched.csv

Full research project:
https://github.com/TasfiaMohtasim/nz-road-crash-severity-prediction
